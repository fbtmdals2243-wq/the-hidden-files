Data & Privacy

The Hidden Files · Public Alpha

Local employee record

The game stores your fictional employee identity, story progress, reports, qualifications, relationships, settings, and work history in this browser's local storage. The static release does not send that record to a server automatically.

Employee archive files

Downloaded archive files are created only when you request them. They contain the same fictional game progress held by the browser and are protected by an integrity checksum. You control where those files are stored and whether they are imported again.

Optional Ministry Network

Account and cloud-save controls remain disabled unless the site owner activates a configured Supabase project. When enabled, account email and the employee archive are processed by that service. Cloud records are never restored onto a device without confirmation.

Recovery and deletion

  • Before a file or cloud restore, the current browser record is saved as one protected recovery checkpoint.
  • The checkpoint can be restored from the Ministry Network desk until it is used or replaced by a later restore.
  • “Delete This Device's Record” removes the local employee record and its recovery checkpoint after employee-number confirmation.
  • Local deletion does not delete a separately stored cloud account or a downloaded archive file.
